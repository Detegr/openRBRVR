# Valve glove assets

Valve's [OpenXR glove models and red texture](https://github.com/ValveSoftware/openxr_engine_plugins/tree/560de2fcab62952d8d6e00760ec6d95eae0f5fd3/assets/valve_hand_models), 
converted for openRBRVR's D3D9 hand renderer.
The meshes and reduced-size texture are compiled into the DLL, so no external assets are needed at runtime.
